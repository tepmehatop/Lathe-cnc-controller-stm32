# Чеклист: всё, что есть в прошивке 7e2, и что из этого есть на STM32

Эталон — прошивка 7e2 для Arduino Mega (`7e2_Mod_LCD4.3_v1.3`, ветки `main` и
`feature/hs800-dro-integration` репозитория 7e2_Mod_4.3-inch-LCD-TFT), её схема `Diagram ELS_V7.jpg` и
инструкция автора. Сверено 2026-11-02.

**Как проверено** (последний столбец):
- **код** — код автора подключён без изменений (`Core/e2/orig/*.ino`) или перенесён дословно в `e2_core.cpp`;
- **сим** — проверено симуляцией на компьютере (`bash tools/run_e2_sim.sh`, 172 проверки), там настоящий код
  ядра и аппаратного слоя, энкодер и таймеры в виртуальном времени;
- **авто** — автоматическая сверка исходников (функции, настройки, переменные, таблицы);
- **железо** — нужна проверка на плате (зависит от реальных проводов, кнопок, моторов).

## 2. Расчёты и движение

| Что | У автора | На STM32 | Проверено |
|---|---|---|---|
| Резьба: шаг мотора по каждому фронту энкодера, дробный делитель Ks/Km | INT0, любой фронт канала A | EXTI на PA1 | сим: шагов на оборот ровно по таблице |
| Старт резьбы с нулевой метки энкодера (попадание в нитку) | Enc_Pos == 0 | то же | сим: повторный проход с той же линии |
| Разгон резьбы (THRD_ACCEL, REPEAt) | | код | сим |
| Синхронная подача: Timer5 от энкодера (вход T5), OCR5A ± 1 — разгон/торможение | Timer5 + перемычка 21–47 | программный счётчик фронтов в том же прерывании | сим: как у Mega (см. BACKLOG-020 про −6…10 %) |
| Асинхронная подача: Timer4, 250 кГц | | TIM12, 250 кГц | сим: 668.5 и 2717.5 шаг/с |
| Ускоренные ходы: Timer2, 500 кГц, разгон MIN→MAX_RAPID_MOTION | | TIM6, 500 кГц | сим: 4902 шаг/с, плавная остановка |

| Конус: X ведомая от Z (Cs/Cm) в тех же прерываниях | | код | сим |
| Тахометр: импульс на оборот шпинделя | вывод 42 | PE8 | сим: 20 импульсов на 20 оборотов |
| Угол шпинделя, требуемый угол метки делилки | | код | сим |
| Пересчёт шагов в мм (без DRO) | | код | код |
| Координаты от блока DRO HS800-2, знаки как у автора | Serial2 | USART2 PA3, `drv_dro` | ранее HIL с эмулятором; железо |
| Переменник подачи (АЦП, 16 отсчётов, мёртвая зона ±4) | A7 | PC1; включается `USE_FEED_POT` | код; железо |

## 7. Настройки (все — в `Core/els_config.h`)

ENC_LINE_PER_REV, MOTOR_Z/X_STEP_PER_REV, SCREW_Z/X, McSTEP_Z/X, REBOUND_X/Z, THRD_ACCEL, FEED_ACCEL,
MIN/MAX_FEED, MIN/MAX_aFEED, Excess_Lag, PASS_FINISH, MAX/MIN_RAPID_MOTION, REPEAt, HC_SCALE_1/10,
HC_START_SPEED_1/10, HC_MAX_SPEED_1/10, HC_X_DIR, HC_Z_DIR, LIN_X, BT_X, BLINC_TIME, BLINC_ON_OFF —
**все 32 параметра автора, те же имена и значения**. Проверки корректности автора (static_assert для

драйверов, длительность импульса STEP, полярность зуммера, переменник подачи, монитор входов.

## 8. Что сделано иначе, чем у автора (и почему)

| Что | Почему |
|---|---|
| «Шпиндель вращается» — по таймеру 1 с, а не по счёту проходов `loop()` | `loop()` на STM32 в десятки раз быстрее |
| Опрос клавиатуры — по `micros()` (40.06 мс), а не флаг Timer1 | нет AVR-таймера; период тот же |
| `millis()` не выключается (у автора `TIMSK0 = 0`) | нужен дисплею и LCD |
| LCD через теневой буфер | прямой вывод занимал бы почти весь цикл |
| Защита длительности импульса STEP | на конусе 45° пауза была бы 0.1 мкс |
| Без переменника подачи (`USE_FEED_POT 0`) стартовая подача — середина диапазона | висящий вход АЦП менял бы подачу сам |
| Таблицы резьб привязаны к механике (сборка не пройдёт при другой) | иначе смена винта молча портила бы резьбы |
| Кнопки упоров работают и при «Ручном», выбранном на экране (`LIMITS_BY_SELECTED_SUBMODE`, BACKLOG-022) | у автора нужен физический переключатель подрежима; во «Внутр./Наруж.» упор по-прежнему не переставить |
| Компенсация люфта винтов `BACKLASH_Z_UM` / `BACKLASH_X_UM` (0 — как у автора, BACKLOG-025) | у автора нет: ноль, взятый движением от детали, давал недорез на величину люфта |
| Значения, которые автор шлёт дисплею только целиком, уходят по изменению (`Display_Watch`) | иначе после кнопок пульта новый дисплей показывал устаревшее |
| Сообщения на новом дисплее горят, пока поднят флаг ядра | как надписи на LCD2004 |

## 9. Не решено (в BACKLOG.md)

- BACKLOG-020 — синхронная подача на 6–10 % меньше заданной (так у автора).
- BACKLOG-021 — механика станка в конфиге.
- GCode с дисплея на новом ядре не исполняется (у автора его не было; был в старом порту STM32) — BACKLOG-001.
- Сохранение настроек во Flash: у автора нет, в старом порту STM32 было — сейчас нет.

## 10. Что проверить на железе (по порядку)

1. Каждый вход — монитором входов (`IO_MONITOR`, отладочный порт 115200): режимы, подрежимы, 5 кнопок,
   джойстик, ускоренный ход, 4 упора, РГИ (A/B, ось, масштаб).
2. «Волна» светодиодов при включении, мигание светодиодов упоров, зуммер.
3. LCD2004: заставка, экраны всех режимов и меню.
4. Дисплей: автотесты `tools/run_all_tests.py`, `tools/run_test_cases.py`, `tools/ui_tap_tests.py`.
5. Блок DRO через эмулятор Mega (`tools/scales_hil_test.py`).
6. Энкодер шпинделя рукой — направление, обороты; затем моторы без нагрузки: подача, резьба, ускоренный ход.

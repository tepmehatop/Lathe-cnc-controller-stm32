Готовые прошивки ELS на ядре 7e2: плата STM32F4DISCOVERY и сенсорный дисплей 4.3", 7" или 10.1".

## Что нового в v0.3.0

- **Дисплей 7" Guition JC1060P470** — три прошивки под варианты платы (см. «Файлы»). Экспериментально: собрано по
  открытым описаниям, на железе не проверялось — ждём отзывов.
- **Инструкция под Windows** — `docs/windows/README.md`: как залить готовую прошивку с GitHub и как собрать свою,
  по шагам с картинками; чем готовая прошивка может не подойти и 9 примеров настроек.
- **Переключатель режимов и экран:** режим меняет тот, кто переключил последним. Если переключатель стоит не там,
  где выбранный на экране режим, в шапке горит янтарное «галетник: РЕЗЬБА». Пока ось едет от джойстика, режим с
  экрана не меняется (как и переключателем).
- **Большой экран (10.1" и 7"):** в M1/M2 плитка «УПОРЫ» — где стоят упоры и длина между ними.
- **Монитор входов через ST-Link** (`tools/io_monitor.py`) — проверка проводки на макетке без USB-UART.
- **Руководство:** примеры конуса и шара по шагам, снимки автоцикла в работе, заметки про 4.3" и 7".
- **Исправления:** барабан выбора значения оставался висеть поверх экрана, если правка закрылась по таймауту;
  асинхронная подача больше 32767 мм/мин показывалась с минусом; прошивка дисплея не собиралась
  из свежей копии без файла настроек Wi-Fi; готовая прошивка STM32 больше не ругается на размер дисплея.

`docs/windows/README.md`, раздел «7 дюймов». Замечания — в Issues на GitHub.

## Под какой станок собрано

Пока прошивки собраны под один станок — WM210F600 с блоком DRO HS800-2. Механика — значения из
`Core/els_config.h`, как у автора 7e2; под реальные винты WM210F600 их ещё предстоит выверить (BACKLOG-021):

| Параметр | Значение |
|---|---|
| Энкодер шпинделя | 1800 линий |
| Винт Z (продольный) | 2 мм |
| Винт X (поперечный) | 1 мм |
| Моторы | 200 шагов/об, микрошаг 4 (800 шагов/об) |
| Координаты | блок DRO HS800-2 на PA3 |
| Компенсация люфта | выключена |

Всё это можно поменять без пересборки — на экране: тап по ⚠ в шапке → «НАСТРОЙКИ» → «МЕХАНИКА»
(шаг винтов, шагов на оборот, микрошаг, люфт, энкодер), там же — «КАЛИБРОВКА»: станок сам измеряет шаг
винта и люфт по линейкам или блоку DRO. Настройки хранятся в последнем секторе флеша
STM32 и переживают перепрошивку; полная очистка чипа (Full chip erase) возвращает значения из конфига.
Если у вас нет блока DRO, прошивка та же: «НАСТРОЙКИ» → «ЛИНЕЙКИ» → «БЕЗ ЛИНЕЕК» или «ЛИНЕЙКИ» (тип,
разрешение и направление по осям), STM32 сохранит выбор и перезапустится. Подробно — руководство
`docs/manual/README.md`, раздел «Настройки».

## Как прошить

**STM32** — подключите mini-USB в разъём ST-Link вверху платы, затем одно из двух:
- STM32CubeProgrammer: ST-LINK → Connect → Open file → адрес `0x08000000` → Download.
- Командная строка: `st-flash write els-stm32-dro.bin 0x08000000`.

**Дисплей** — подключите по USB, затем одно из двух:
- В браузере (Chrome или Edge): https://espressif.github.io/esptool-js/ → Connect → адрес `0x0` → файл → Program.
- Командная строка: `esptool.py write_flash 0x0 els-display-jc8012p4a1c.bin`.
  Для 4.3" — тот же адрес, файл `els-display-jc4827w543.bin`.

Wi-Fi дисплея (G-код) в готовой прошивке не настроен — сеть задаётся на экране: тап по ⚠ → «НАСТРОЙКИ» →
«WI-FI». Пошагово для Windows — прошивка, сборка своей прошивки, что настроить — `docs/windows/README.md`.

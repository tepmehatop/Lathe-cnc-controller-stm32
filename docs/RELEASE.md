Готовые прошивки ELS на ядре 7e2: плата STM32F4DISCOVERY и сенсорный дисплей 7" или 10.1".

**Дисплей 4.3" (JC4827W543) не поддерживается после v0.4.1** — интерфейс на 480×272 уже не помещается.
Последняя прошивка для 4.3" — в релизе v0.4.1; в этот и следующие релизы файл для 4.3" не входит.

## Что нового в v0.4.1

> **После обновления Wi-Fi дисплея выключен.** Чтобы открыть веб-страницу (G-код, файлы): ⚠ в шапке →
> «НАСТРОЙКИ» → «WI-FI» → «РОУТЕР» (ваша сеть сохранена, подключится сама) или «ТОЧКА ДОСТУПА». Выбор
> запоминается.

- **Wi-Fi — ВЫКЛ / РОУТЕР / ТОЧКА ДОСТУПА.** Три кнопки на экране WI-FI. В режиме РОУТЕР дисплей больше не
  поднимает сам свою точку доступа, если роутер не ответил, — повторяет подключение. При ВЫКЛ радио выключено и сети
  не ищутся.
- **«БЫСТРО» в экранном джойстике работает.** Теперь это переключатель: тап — «ВКЛ», стрелки едут ускоренным ходом,
  ещё тап — «выкл» (держать вместе со стрелкой было нельзя: экран понимает одно касание). При закрытии джойстика
  выключается.
- **Джойстик сам не закрывается.** Раньше он закрывался через 30 секунд без касаний — выглядело как «моргнул и
  перешёл на главный экран». Закрыть — ✕ или «⚡».
- **«ИЗ КОНФИГА»** ставит заводские значения механики из прошивки (люфт по умолчанию 0) и сразу их сохраняет — так и
  задумано. Старые цифры больше не мелькают, на экране «ЗАВОДСКИЕ ЗНАЧЕНИЯ» и окно с объяснением. Отменить свои
  правки — «ЗАКРЫТЬ», не нажимая «СОХРАНИТЬ».
- **Диагностика экрана (10.1" и 7").** Внизу экрана «НАСТРОЙКИ» — строка «Диагностика»: сколько раз дисплей
  перезапускался сам (и почему) и сколько раз матрица не получила кадр вовремя. Если экран моргнул, пришлите эти
  числа — так видно, прошивка это или питание/шлейф.

## Что было в v0.4.0

- **Жесты — везде одинаково.** Тап — открыть, выбрать, ввести; двойной тап — только подменю (по ⌀ — следующий
  подэкран, по шагу в M3 — тип резьбы); удержание 2 секунды с подсказкой «ДЕРЖИТЕ» — всё, что стирает (обнулить
  ось, «ИЗ КОНФИГА», забыть сеть). Тап по позиции Z / X / ⌀ — клавиатура, удержание Z / X — ноль. Скрытые серии
  нажатий (демо-режим, тест-режим) убраны.
- **Экранный джойстик — новый.** Позиции Z и X видны прямо на нём (тап — ввод, удержание — ноль), крест по
  центру, стрелки Z синие, X фиолетовые. Ось едет, пока держите стрелку, — как механический джойстик, автоцикл
  тоже; отпустили или пропала связь — ось встаёт. «БЫСТРО» — держать; подача — тап, ввести.
- **Подача и съём — с клавиатуры** во всех режимах. Число вне пределов не принимается — окно «НЕ ПРИНЯТО»;
  STM32 тоже не берёт подачу больше 0.25 мм/об и асинхронную больше 400 мм/мин.
- **G-код (M8):** запуск со страницы сам включает M8; пока программа идёт, экран заблокирован, справа —
  крупная «СТОП» и «ПАУЗА» / «ПРОДОЛЖИТЬ»; пауза останавливает оси сразу, посреди строки. Неизвестное направление
  линеек — ошибка сразу, до первого движения.
- **Механика станка:** окно «НЕ СОХРАНЕНО» объясняет, что не получится и что поменять (шагов на мм, нужная полоса
  для вашего энкодера); новое руководство `docs/manual/mechanics.md` с рисунками; 16 механик проверены на стенде.
- **«STM32 ПЕРЕЗАПУСТИЛАСЬ»** — если плата перезапустилась сама (просело питание, зависла), экран скажет.
- **Исправлено:** «ВВОД» на клавиатуре нажимал кнопку под окном (ЗАКРЫТЬ, ИЗ КОНФИГА); «ИЗ КОНФИГА» срабатывал
  от случайного касания; статус на экране «ЛИНЕЙКИ» наезжал на заголовок, поля линеек менялись при блоке DRO;
  «УПОРЫ» не помещались в плитку; значок в окне ввода диаметра; двойной тап в делилке сдвигал метку.

Файл дисплея содержит загрузчик, таблицу разделов и программу, поэтому прошивается целиком с адреса 0x0.

**7" — экспериментально:** у автора проекта этого дисплея нет, прошивка собрана по открытым описаниям платы
и на железе не проверялась. Какой из трёх файлов брать и что делать, если экран белый или чёрный, —
`docs/windows/README.md`, раздел «7 дюймов». Замечания — в Issues на GitHub.

## Под какой станок собрано

Пока прошивки собраны под один станок — WM210F600 с блоком DRO HS800-2. Механика — значения из
`Core/els_config.h`, как у автора 7e2; под реальные винты WM210F600 их ещё предстоит выверить (BACKLOG-021):

| Параметр | Значение |
|---|---|
| Энкодер шпинделя | 1800 линий |
| Винт Z (продольный) | 2 мм |
| Винт X (поперечный) | 1 мм |
| Моторы | 200 шагов/об, микрошаг 4 (800 шагов/об) |
| Координаты | блок DRO HS800-2 на PA3 |
| Компенсация люфта | выключена |

Всё это можно поменять без пересборки — на экране: тап по ⚠ в шапке → «НАСТРОЙКИ» → «МЕХАНИКА»
(шаг винтов, шагов на оборот, микрошаг, люфт, энкодер), там же — «КАЛИБРОВКА»: станок сам измеряет шаг
винта и люфт по линейкам или блоку DRO. Настройки хранятся в последнем секторе флеша
STM32 и переживают перепрошивку; полная очистка чипа (Full chip erase) возвращает значения из конфига.
Если у вас нет блока DRO, прошивка та же: «НАСТРОЙКИ» → «ЛИНЕЙКИ» → «БЕЗ ЛИНЕЕК» или «ЛИНЕЙКИ» (тип,
разрешение и направление по осям), STM32 сохранит выбор и перезапустится. Подробно — руководство
`docs/manual/README.md`, раздел «Настройки».

## Как прошить

**STM32** — подключите mini-USB в разъём ST-Link вверху платы, затем одно из двух:
- STM32CubeProgrammer: ST-LINK → Connect → Open file → адрес `0x08000000` → Download.
- Командная строка: `st-flash write els-stm32-dro.bin 0x08000000`.

**Дисплей** — подключите по USB, затем одно из двух:
- В браузере (Chrome или Edge): https://espressif.github.io/esptool-js/ → Connect → адрес `0x0` → файл → Program.
- Командная строка: `esptool.py write_flash 0x0 els-display-jc8012p4a1c.bin`.
  Для 4.3" — тот же адрес, файл `els-display-jc4827w543.bin`.

Wi-Fi дисплея (G-код) в готовой прошивке не настроен — сеть задаётся на экране: тап по ⚠ → «НАСТРОЙКИ» →
«WI-FI». Пошагово для Windows — прошивка, сборка своей прошивки, что настроить — `docs/windows/README.md`.

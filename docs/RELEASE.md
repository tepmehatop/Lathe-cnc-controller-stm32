Готовые прошивки ELS на ядре 7e2: плата STM32F4DISCOVERY и сенсорный дисплей 4.3" или 10.1".

## Файлы

| Файл | Куда | С какого адреса |
|---|---|---|
| `els-stm32-dro.bin` | STM32F4DISCOVERY, координаты от блока DRO HS800-2 | `0x08000000` |
| `els-display-jc4827w543.bin` | дисплей 4.3" JC4827W543 (ESP32-S3) | `0x0` |
| `els-display-jc8012p4a1c.bin` | дисплей 10.1" JC8012P4A1C (ESP32-P4) | `0x0` |
| `SHA256SUMS.txt` | контрольные суммы | — |

Файл дисплея содержит загрузчик, таблицу разделов и программу, поэтому прошивается целиком с адреса 0x0.

## Под какой станок собрано

Пока прошивки собраны под один станок — WM210F600 с блоком DRO HS800-2. Механика — значения из
`Core/els_config.h`, как у автора 7e2; под реальные винты WM210F600 их ещё предстоит выверить (BACKLOG-021):

| Параметр | Значение |
|---|---|
| Энкодер шпинделя | 1800 линий |
| Винт Z (продольный) | 2 мм |
| Винт X (поперечный) | 1 мм |
| Моторы | 200 шагов/об, микрошаг 4 (800 шагов/об) |
| Координаты | блок DRO HS800-2 на PA3 |
| Компенсация люфта | выключена |

Механику можно поменять без пересборки — на экране: двойной тап по ⚠ в шапке → «МЕХАНИКА СТАНКА»
(шаг винтов, шагов на оборот, микрошаг, люфт, энкодер). Настройки хранятся в последнем секторе флеша
STM32; полная очистка чипа (Full chip erase) возвращает значения из конфига. Если нет блока DRO, соберите прошивку сами: без линеек — `pio run -e stm32f407_discovery`,
с линейками напрямую — `pio run -e stm32f407_scales`. Подробно — в `docs/README.md`.

## Как прошить

**STM32** — подключите mini-USB в разъём ST-Link вверху платы, затем одно из двух:
- STM32CubeProgrammer: ST-LINK → Connect → Open file → адрес `0x08000000` → Download.
- Командная строка: `st-flash write els-stm32-dro.bin 0x08000000`.

**Дисплей** — подключите по USB, затем одно из двух:
- В браузере (Chrome или Edge): https://espressif.github.io/esptool-js/ → Connect → адрес `0x0` → файл → Program.
- Командная строка: `esptool.py write_flash 0x0 els-display-jc8012p4a1c.bin`.
  Для 4.3" — тот же адрес, файл `els-display-jc4827w543.bin`.

Wi-Fi дисплея (G-код) в готовой прошивке не настроен. Чтобы его настроить, соберите прошивку сами со своим
`ELS_Display/include/wifi_config.h`.
